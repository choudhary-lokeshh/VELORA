# Generated Android assets

Every file in this directory is written by `pnpm mobile:assets` from the
`sparkle` mark in `apps/mobile/src/design/icons.tsx` and the `canvas` and
`ember` tokens in `apps/mobile/src/design/tokens.ts`. Do not edit them by
hand: the next run overwrites them, and a hand-edited icon is a visual
nobody approved. Change the mark or the token and run the script again.
